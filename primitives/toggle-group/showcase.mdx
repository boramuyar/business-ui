## Filter chips

`variant="chip"` with `type="multiple"` and `spacing={1}` turns the group into filter chips. Each chip
switches on and off on its own, and with none on the list shows everything, so there is no "All" chip.

<Preview name="toggle-group-chips" />

## Segmented

`variant="segmented"` with `type="single"` draws a segmented control: the modes share a muted track and the picked one
is raised. It fills its cell and always keeps one mode on, so clicking the picked mode again changes nothing.

<Preview name="toggle-group-segmented" />

## Usage

Use `toggle-group` for formatting toolbars and exclusive view switches. For
actions without pressed state use `button-group`.
