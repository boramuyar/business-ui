## Basic

The trigger looks like a select; it opens a list with a search box above it. Typing filters by label, and picking
an option closes the list. Inside a field, spread `useFieldControl()` onto it.

## Server search

When the options live on a server, pass `onSearchChange` and give the matches as `options`, with `loading` while
they load. `knownOptions` keeps the picked value's label when the matches leave it out.

<Preview tall name="combobox-search" />

## Usage

Use `combobox` for one value from a list long enough to search, or one people know by name. For several values use
`multi-select`; for 6 to 15 options people scan use `select`; for commands use `command`. It is built on `popover`
and `command`, like `multi-select`, so the two open, search and pick the same way.
