## Composition

`EmptyContent` holds calls to action; the whole state nests inside a `card`.

<Preview name="empty-composition" className="items-stretch" />

## Usage

Use `empty` whenever a list, table, or section can be empty - always explain
what belongs there and offer the next action. The showcase's own Blocks page
uses it.
