## Variants

One file shows its name next to the button. With `multiple`, each pick adds to
a list where files can be removed again.

## Composition

Inside a `field`, the label points at the hidden input through `id`.

<Preview name="file-input-field" />

## Usage

The native input stays in the form, so a plain form submit sends the files
that are listed. Use `value` and `onValueChange` to control the list.
