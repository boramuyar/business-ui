## Composition

A loading list built from the real `item` rows. `SkeletonText` sits inside the title and description, so each row is exactly as tall as a loaded one.

<Preview name="skeleton-composition" />

## Usage

Every loading state is a skeleton of the screen it becomes. Build it from the
same components and put `SkeletonText` with sample text where the text will be,
so nothing moves when the data arrives. Spinners only mark work that is running
right now, such as a button's action; for measurable progress use `progress`.
