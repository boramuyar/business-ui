## Variants

Vertical scrolling with a styled scrollbar.

<Preview name="scroll-area-vertical" />

Horizontal scrolling needs an explicit `ScrollBar orientation="horizontal"`.

<Preview name="scroll-area-horizontal" />

## Usage

Use `scroll-area` where native scrollbars would break the design - sidebars,
dropdown lists, code blocks. Content must have a constrained size for
scrolling to engage.
