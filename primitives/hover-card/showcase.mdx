## Composition

A profile preview composing `avatar` and `badge`.

<Preview name="hover-card-composition" tall />

## Usage

Use `hover-card` for optional previews that must not require a click. It does
not work on touch - never hide essential content in one; use `popover` for
content the user must reach on every device.
