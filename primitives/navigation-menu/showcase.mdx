## Variants

Triggers open content panels; plain links use the shared trigger style.

<Preview tall name="navigation-menu-variants" />

## Usage

Use `navigation-menu` for horizontal top-level site navigation with rich
panels. For app sidebars use `sidebar`; for action menus use
`dropdown-menu`.
