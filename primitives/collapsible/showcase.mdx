## States

A controlled collapsible with a chevron trigger - the first row stays
visible, the rest toggles.

<Preview name="collapsible-controlled" />

## Usage

Use `collapsible` for one optional region - advanced settings, long lists,
sidebar groups. For multiple labeled sections use `accordion`.
