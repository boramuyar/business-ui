## Composition

`AlertDialogMedia` adds an icon inside the header; `AlertDialogInner` holds
supporting body copy between header and footer.

<Preview name="alert-dialog-composition" tall />

## Usage

Use `alert-dialog` only when the user must explicitly confirm or cancel - it
traps focus and has no dismiss-on-outside-click. For ordinary tasks use
`dialog`.
