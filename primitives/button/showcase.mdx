## Usage

Use the default variant for the one primary action (at most one per header,
dialog or form). Use `outline` for other actions next to it, `secondary` for
quiet actions in dense areas, `ghost` for toolbar and icon actions,
`destructive` only inside an `alert-dialog` or a danger section, and `link`
for inline navigation.
