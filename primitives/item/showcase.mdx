`ItemMedia` variants (icon, avatar), `ItemActions`, links via `asChild`, and
grouped rows with separators.

## Loading more

A list that loads its next page as it scrolls ends in `ItemLoadingMore` while that page loads: a spinner and a
short label, centered. The first page loads as a skeleton of the rows instead.

<Preview name="item-loading-more" className="flex-col items-stretch" />

## Usage

Use `item` for structured list rows - files, members, notifications. For
standalone content surfaces use `card`; for tabular data use `table`.
