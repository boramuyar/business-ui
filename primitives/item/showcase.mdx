## Separated

Rounded rows that sit close together take an `ItemSeparator inset` between them: a subtle line that ends at the
rows' content edge, before their corners round, so a row's hover fill never runs past it.

<Preview name="item-separated" className="flex-col items-stretch" />

## Selected

Set `data-selected` on the row that is the current one, such as the record open beside the list. It takes the
brand selection fill of a selected table row, in every variant, and keeps it under the pointer. Mark its title with
`aria-current` too, so screen readers announce it.

<Preview name="item-selected" className="flex-col items-stretch" />

## Loading more

A list that loads its next page as it scrolls ends in `ItemLoadingMore` while that page loads: a spinner and a
short label, centered. The first page loads as a skeleton of the rows instead.

<Preview name="item-loading-more" className="flex-col items-stretch" />

## Usage

Use `item` for structured list rows - files, members, notifications. For
standalone content surfaces use `card`; for tabular data use `table`.
