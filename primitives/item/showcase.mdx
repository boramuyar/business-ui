## Composition

`ItemMedia` variants (icon, avatar), `ItemActions`, links via `asChild`, and
grouped rows with separators.

<Preview name="item-composition" className="flex-col items-stretch" />

## Usage

Use `item` for structured list rows - files, members, notifications. For
standalone content surfaces use `card`; for tabular data use `table`.
