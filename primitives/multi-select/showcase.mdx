---
title: Multi Select
description: Pick several values from a searchable list; the picked values show as tags under the field.
status: stable
---

## Field

The trigger looks like a `select` and says what is picked: the placeholder, or a short summary such as "4 of 6
sheets". It opens a list over the page, so nothing around the field moves: search, an optional Select all, and a
checkbox row for each option. Each picked value becomes a tag below the trigger, never inside it, and its × removes
it. A disabled option can't be picked or removed.

<Preview tall name="multi-select-field" />

## Search on a server

When the options live on a server, such as everyone in a directory, give `onSearchChange`: it gets the search as
people type, so the app can search there and pass the matches as `options`, with `loading` while they load. The
list then shows the matches as they come, without filtering them again or offering Select all, and the trigger
counts only what is picked. A picked value keeps its tag while the matches leave it out; values picked before the
list opened get their labels from `knownOptions`.

## States

Nothing picked shows the placeholder. `invalid` on the field turns the trigger destructive, and `disabled` turns off
the trigger and the tags' remove buttons.

<Preview tall name="multi-select-states" />

## Usage

Use `multi-select` for several values from a list that is too long for checkboxes in the form. For one value use
`select` or `combobox`; for category filters in a toolbar use `toggle-group` with `variant="chip"`.
