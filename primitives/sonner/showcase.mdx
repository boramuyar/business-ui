## Usage

Mount the `Toaster` once at the app root (this showcase already does), then
call `toast()` from anywhere. It follows the `.dark` class on `<html>`, so no
theme provider is needed. The install-command copy buttons here use it. Use toasts for transient feedback; for persistent
messages use `alert`.
